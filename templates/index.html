What is Disk Scheduling?

Disk scheduling is a mechanism that determines the order in which disk I/O requests are serviced. The disk head moves across cylinders to read/write data, and efficient scheduling algorithms minimize the total head movement, reducing seek time and improving system performance.

Key Components:

  • Disk Head: The read/write mechanism that moves across the disk surface
  • Cylinders: Concentric circles on the disk where data is stored (0-199 in this simulation)
  • Seek Time: Time taken to move the head from one cylinder to another

Available Algorithms:

  • FCFS (First Come First Serve): Requests are served in the order they arrive
  • SSTF (Shortest Seek Time First): Serves the closest cylinder request first
  • SCAN: Head moves from one end to other, serving requests along the way
  • CSCAN (Circular SCAN): Similar to SCAN but moves in one direction only
